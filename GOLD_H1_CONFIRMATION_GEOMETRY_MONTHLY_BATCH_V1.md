# Gold H1 Confirmation Geometry Monthly Batch V1

## Purpose

Run the already frozen H1 confirmation-only V2 control and the complete frozen 3-entry by 4-stop geometry matrix unattended over every full calendar month from June 2022 through December 2024. This is an exposed historical extension and receives no independent-validation credit.

## Immutable scope

- Preserve the sealed January-May 2022 geometry audit and all predecessor artifacts unchanged.
- Use only the sealed `gold_casebook_v01/price_bars.jsonl.gz` source, whose exclusive endpoint is 2025-01-01.
- Process exactly 31 months: June-December 2022, January-December 2023, and January-December 2024.
- Keep calendar 2025 and 2026 closed.
- Acquire no data, contact no provider, and incur no charge.
- Preserve the original V2 population construction, H1 direction, M5 confirmation/reclaim lifecycle, absolute H1 target, month-end deadline and stop-first ambiguity rule.
- Apply all twelve policies from `GOLD_H1_CONFIRMATION_ENTRY_STOP_GEOMETRY_AUDIT_V1` unchanged. Do not choose a policy month by month.
- Preserve gross-before-cost and overlap-unconstrained accounting so results remain comparable with January-May. Report the `$50` fixed-risk illustration, but do not call it live PnL.

## Mandatory rehearsal gate

Before opening June 2022, the generalized monthly runner must reproduce every January-May 2022 case context and all 3,912 sealed matrix rows exactly, including row identities and hashes. A rehearsal failure stops the batch.

## Unattended execution and recovery

- Parse primary and independent reference source streams sequentially.
- Process and seal one calendar month at a time.
- Use atomic files and append-only log records.
- A restart may skip only a completed checkpoint whose source, protocol, implementation and payload hashes verify exactly.
- Never silently replace, repair or omit a failed month.
- Update a machine-readable status file after every month, including current stage, month, completed count, process ID and last error.
- The detached process must not depend on an active Codex turn.

## Monthly outputs

For every month produce:

- complete setup and execution ledger;
- all twelve geometry-policy rows for every executed control setup;
- complete monthly performance matrix;
- primary/reference equality certificate;
- concise Markdown report;
- one continuous white H1/M15/M5 interactive chart using the unchanged V2 control as the default overlay;
- browser-level chart certification and screenshot.

The chart must show local entry, stop and target segments rather than lines spanning the complete chart. It must support timeframe selection, pan, zoom, full-month view and ledger-row selection.

## Final outputs and verdict

Produce a chronological aggregate report, monthly matrix CSV, account-equity illustration for the unchanged control, index page linking every monthly chart, complete cryptographic manifest and an honest completion/failure verdict. Report all months separately and combined. Do not rank or select a replacement policy as a deployable strategy from this exposed extension.
